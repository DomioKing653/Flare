# Contributing

Thanks for your interest in contributing to **Vetrex**!

Even though Vetrex is a fun project, I still take it seriously—so any help is greatly appreciated.

## Ways to Contribute

1. **Break stuff**
   Try to break the compiler and then create an issue describing what happened.
2. **Add features**
   Suggest feature at issue ot try to fix one. Create new brach at your fork, implement fix or feature. Then open pull request and I'll merge it afterwords.

3. **Improve documentation**
   Help make things clearer and easier to understand.
---

## AI usage

Using AI tools to help write a contribution is fine, but you're expected to understand, test, and take responsibility for anything you submit. See [AI_POLICY.md](AI_POLICY.md) for what's and isn't okay - it covers unreviewed AI output, hallucinated APIs, and mass-generated issues/PRs specifically.

Thanks again for your interest, and see you around :>
